Privacy policy

Karthik Uploader is a personal tool used only by its owner on his own computer. Last updated 15 October 2026.

What it accesses

With the owner's Google sign-in, it uses the YouTube Data API and YouTube Analytics API to upload and schedule videos, set titles, descriptions, thumbnails and captions, list videos, and read statistics and public comments for the owner's own channels.

How data is stored

Sign-in tokens and any data read are stored only on the owner's computer. Nothing is sold, shared with third parties, or used for advertising. Data is not transferred anywhere except to Google's own APIs.

Your control

Access can be removed at any time at myaccount.google.com/permissions. Use of Google user data follows the Google API Services User Data Policy.
